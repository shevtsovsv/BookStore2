## Архитектура корзины

Интерфейс корзины строится на трёх основных слоях:

1.  **Визуальный слой (HTML/CSS):**

- Отвечает за отображение товаров, итоговой суммы, кнопок управления.
- Включает разметку и стили для корзины, списка товаров, блока итоговой суммы и кнопок.

2.  **Динамический слой (JavaScript):**

- Управляет состоянием корзины: добавление, удаление, изменение количества товаров.
- Обновляет DOM при изменениях (перерисовка списка, суммы, состояния кнопок).
- Реализует обработчики событий для кнопок и полей ввода количества.

Блок "Структура файлов корзины" был добавлен сразу после архитектурного раздела, перед "Структура страницы корзины". Вот как он выглядит:

public/
├── html/
│ ├── cart.html # Страница корзины
│ └── checkout.html # Оформление заказа
├── style/
│ ├── cart.css # Стили корзины
│ └── components.css # Общие компоненты
├── scripts/
│ ├── cart-data.js # Хранилище и логика корзины
│ ├── cart.js # Рендер и обработка событий
│ └── checkout.js # Логика оформления заказа
└── img/
├── cart/ # Изображения для корзины
└── icons/ # Иконки управления

3.  **Серверный слой (API):**

- Получает и сохраняет состояние корзины пользователя.
- Обрабатывает оформление заказа, проверку наличия товаров, расчёт итоговой суммы.
- Возвращает ответы для отображения статуса заказа и ошибок.

### Взаимодействие слоёв

- Пользователь взаимодействует с корзиной через визуальный слой.
- Динамический слой реагирует на действия пользователя, обновляет интерфейс и отправляет запросы на сервер.
- Серверный слой принимает запросы, обрабатывает их и возвращает результат для отображения.
