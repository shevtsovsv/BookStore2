# 📚 Полное руководство по созданию проекта "Книжный интернет-магазин"

## 🎯 Описание проекта

Этот набор руководств поможет вам создать с нуля полнофункциональный интернет-магазин книг с использованием современных веб-технологий.

### ⚡ Что вы получите в результате:

- ✅ Современный веб-магазин с адаптивным дизайном
- ✅ Полную систему аутентификации и авторизации
- ✅ Корзину покупок с оформлением заказов
- ✅ Административную панель для управления
- ✅ RESTful API с полной документацией
- ✅ Готовность к деплою на VDS/VPS

### 🛠 Технологический стек

**Backend:**

- Node.js + Express.js
- PostgreSQL + Sequelize ORM
- JWT аутентификация
- bcrypt для хеширования паролей

**Frontend:**

- HTML5, CSS3, Vanilla JavaScript
- Адаптивный дизайн (Mobile-first)
- AJAX/Fetch API
- Модульная архитектура

**DevOps:**

- PM2 для процесс-менеджмента
- Nginx как reverse proxy
- Переменные окружения (.env)
- CI/CD готовность

## 📁 Структура файлов проекта

После завершения всех руководств у вас будет следующая структура:

```
bookstore/
├── 📁 config/                 # Конфигурация БД
├── 📁 migrations/             # Миграции Sequelize
├── 📁 models/                 # Модели данных
├── 📁 seeders/                # Тестовые данные
├── 📁 src/
│   ├── 📁 controllers/        # Контроллеры API
│   ├── 📁 middleware/         # Middleware функции
│   ├── 📁 routes/            # Маршруты API
│   └── 📁 utils/             # Утилиты
├── 📁 public/                # Статические файлы
│   ├── 📁 html/              # HTML страницы
│   ├── 📁 scripts/           # JavaScript файлы
│   ├── 📁 style/             # CSS стили
│   └── 📁 img/               # Изображения
├── 📁 tests/                 # Тесты
├── 📁 docs/                  # Документация
├── .env                      # Переменные окружения
├── .gitignore               # Git исключения
├── ecosystem.config.js      # PM2 конфигурация
├── package.json            # Зависимости npm
└── server.js               # Точка входа
```
