# Урок 25. Оформление заказа и интеграция с сервером

В этом уроке рассмотрим процесс оформления заказа и отправку данных корзины на сервер.

## Основные шаги
1. Проверка корзины перед оформлением (не пуста, все количества корректны)
2. Формирование объекта заказа
3. Отправка заказа на сервер через fetch
4. Обработка ответа (успех/ошибка)

## Пример JS-кода

```js
function checkout() {
  if (cart.length === 0) {
    alert('Корзина пуста!');
    return;
  }
  const order = {
    items: cart.map(item => ({ id: item.id, qty: item.qty })),
    total: getCartTotal()
  };
  fetch('/api/cart/checkout', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(order)
  })
    .then(res => res.json())
    .then(data => {
      if (data.success) {
        alert('Заказ успешно оформлен!');
        cart = [];
        renderCart();
      } else {
        alert('Ошибка оформления заказа: ' + data.message);
      }
    })
    .catch(() => alert('Ошибка связи с сервером'));
}
```

## UX-детали
- Кнопка оформления заказа блокируется, если корзина пуста
- После успешного оформления корзина очищается
- Сообщения об ошибках отображаются пользователю

На этом цикл уроков по корзине завершён. При необходимости можно добавить отдельные уроки по тестированию и расширению функционала.
