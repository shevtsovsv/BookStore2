## 🚀 Быстрый старт:

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/shevtsovsv/BookStore2.git
   cd BookStore2
   ```

2. **Установите зависимости:**

   ```bash
   npm install
   ```

3. **Настройте базу данных:**

   ```bash
   npm run db:create
   npm run db:migrate
   npm run db:seed
   ```

4. **Запустите проект:**

   ```bash
   npm start
   ```

5. **Откройте в браузере:**
   ```
   http://localhost:3000
   ```
