# 📚 Django BookStore - Полное руководство

## 🎯 Введение

Добро пожаловать в полное руководство по созданию Django версии проекта BookStore!

## 🆘 Получение помощи

### Если что-то не работает:

1. **Проверьте логи:**
   ```bash
   python manage.py runserver
   # Смотрите вывод в консоли
   ```

2. **Проверьте проект:**
   ```bash
   python manage.py check
   ```

3. **Используйте Python shell:**
